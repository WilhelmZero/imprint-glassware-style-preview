# Imprint Works Group — Style Preview

Three glassware website concepts: Original Studio, Noir Atelier, and Terra Journal.

Open `index.html` for the style comparison. Each concept includes the homepage, product categories, customization, company pages, articles, and a concept image gallery.

This is a static design preview, separate from the live WordPress website. Contact forms are demonstrations and do not send or store inquiries. AI-generated images illustrate design concepts rather than exact catalog products.

GitHub Pages serves the `main` branch root. No build dependencies are required.
